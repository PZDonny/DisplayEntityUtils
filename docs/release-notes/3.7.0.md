**Release Highlights**
- New Rotation Commands💻
- New Skript Syntax📜
- New and Breaking API Changes 🔨

## Command Changes

### <ins>New Commands</ins>
- Added `/deu group setrotation`
  - Set a group's rotation on a given local axis
  - Permission: `deu.group.transform`
- Added `/deu display setrotation`
  - Set a display's rotation on a given local axis
  - Permission: `deu.display.transform`


## Skript
### <ins>New Syntax</ins>

- Added `Active Group/Part - Rotation`
  - Get/Set an active group or active part's display transformation rotation
  ```yml
  set {_activepart}'s deu y rotation to 90 degrees
  set {_activegroup}'s deu rotation to {_vector}
  set {_quaternion} to {_activepart}'s deu rotation
  ```

## API Changes
> [!NOTE]
>**New Version:** `3.7.0`

### <ins>Additions/Changes</ins>
- Added `ActiveGroup#setRotation`, to change a group's transformation rotation, rather than entity pitch and yaws
- Added `getRotation`, `resetRotation`, and `rebaseRotation` to `ActiveGroup`
- Added `Active#rotate` using an `Axis` for rotation
- Added `ActivePart#setRotation` to change a display part's transformation rotation

### <ins>Breaking Changes</ins>
- Removed `SpawnedDisplayEntityPart#getCreationTime`
- Changed `#setRotation` to `#setEntityRotation` in `Active`
- Renamed `PivotAxis` class to `Axis`

## QOL
- Added group rotation info to `/deu group info`
