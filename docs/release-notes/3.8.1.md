**Release Highlights**
- Breaking API Changes 🔨
- Bug Fixes 🐛

## API Changes
> [!NOTE]
>**New Version:** `3.8.1`

### <ins>Breaking Changes</ins>
- Removed `IS_DEV_VERSION` field from `VersionUtils`
- Changed `DisplayStorage` and `DBDisplayStorage` to abstract classes to accept Logger in constructor
  - May require recompilation of plugins depending on `DisplayEntityUtils`


## Bug Fixes / QOL
- Corrected logic for `VersionUtils#cleanVersionString`
- Fixed an `NPE` that occurred when trying to message a player after deleting groups/animations
- Fixed deleting groups/animations not working as intended when using `MySQL` storage
- Fixed saving/deleting animations not working as intended when using `MongoDB` storage
