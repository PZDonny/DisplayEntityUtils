**Release Highlights**
- Gizmo Changes 📐
- New Commands 💻
- New and Breaking API Changes 🔨
- Bug Fixes 🐛

## Gizmo Changes
- Snapped movements can be toggled by using `SNEAK + OFFHAND`
- The snap value can be changed by `SCROLLING (With selected axis)`
- A selected group / entity can be cloned by `LEFT CLICKING` the pivot / white cube at the center of the Gizmo
- Translating in teleport mode snaps to world grid when snapping is enabled

## Command Changes

### <ins>New Commands</ins>
- Added `/deu display roundtranslation`
    - Remove the decimal portion of your selected display's translation. 
      - (Ex: X translation of `12.25` would become `12.0`).
    - Permission: `deu.display.transform`
- Added `/deu gizmo snapvalue`
    - Set the snapping value for a selected Gizmo control
    - Permission: `deu.gizmo.use`
- Added `/deu gizmo toggglesnap`
    - Toggle the snapping of gizmo control movements
    - Permission: `deu.gizmo.use`

## API Changes
> [!NOTE]
>**New Version:** `3.8.0`

### <ins>Additions/Changes</ins>
- Added `DisplayStorage#isEnabled` to see if a storage location is enabled
- Add paginated `#getGroupTags` and `#getAnimationTags` to `DisplayStorage`
- Added `LoadMethod#getDisplayStorage`

### <ins>Breaking Changes</ins>
- Removed `DisplayAnimationManager#getSavedDisplayAnimations` in favor of `DisplayStorage#getAnimationTags`
- Removed `DisplayGroupManager#getSavedDisplayEntityGroups` in favor of `DisplayStorage#getGroupTags`


## Bug Fixes / QOL
- Fixed an issue where using a `MongoDB` database without passing a `connectionString` in the config 
generated an incorrect connection string
- Added minor optimization to listing group and animation tags from a database
- All plugin permissions are now correctly registered
- Player movement is now stopped after selecting a Gizmo control
- Fixed `/deu parts clone` requiring a tag to be added to a cloned part, rather than being optional
